# Security policy

The latest v0.1 patch release is supported. This tool generates a local development environment; production hosting is outside its security boundary.

Please report suspected vulnerabilities using GitHub's private vulnerability reporting on this repository (Security → Report a vulnerability). If the private option is unavailable, contact the maintainer through their GitHub profile before posting sensitive details publicly. Do not attach `.env`, real credentials or installed MODX configuration to public issues.

Include the installer version, host OS/architecture, PHP and Docker versions, a minimal reproduction and the impact you observed. Redact secrets. Reports concerning MODX itself should follow the MODX project's security reporting process.
